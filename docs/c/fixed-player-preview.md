# 固定玩家运行指南

游戏只使用每人一台手机模式。旧的传手机页面、路由和本地游戏会话入口已删除。

运行：在 D:\Software Project\app 中执行 npm run dev:players。手机和电脑处于可互通网络，使用终端的 Network 地址打开测试入口。选择普通或融合玩法，创建后由主持人分发不同座位的邀请链接；每人只打开自己的链接。localhost链接仅可用于同一电脑的多窗口测试。

融合玩法支持4–12人，普通玩法4–20人。融合玩法所有人确认自己的词后轮流作画。当前使用明确标记的模拟画布：选择图形和模拟评分结果后提交。其余玩家只等待；作画结束后所有人回顾作品10秒，再各自投票。评分失败或超时不影响投票和胜负。

主持人也是参与者，只有主持人可以结束和重开。刷新自己的邀请URL保持身份；重开自动同步到所有设备。真实小程序登录和平台服务仍由A接入；H5共享服务仅为开发预览，不进入生产包，重启会丢失测试会话。B负责真实画布、笔画同步和评分展示。当前每位玩家的测试票据由开发主持人分发，不等于微信身份认证。

真实接入点仍是 UcPlayerPort，个人界面不创建游戏引擎或切换操作者。融合补充 submitDrawing 方法、artworks 快照字段，规则与适配说明见 hybrid-rules.md。
