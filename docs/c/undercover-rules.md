# 谁是卧底 · C1-P0 试玩规则



这些规则沿用已有代码，并补上私密领词流程。它们是可评审的试玩默认值，尚无团队正式确认记录；不宣称取代正式需求 v1.1。下一轮可以依据评审修改。

## 本轮规则与待确认项

1. 经典模式 4–20 人。4–6 人默认 1 名卧底，7–12 人 2 名，13–20 人 3 名。至少有一名卧底，平民人数必须大于卧底和白板之和。
2. 每人可填写昵称，空昵称显示“玩家N”，界面同时显示座位号。1号位是本机试玩主持人。
3. 每局随机分配角色并抽一个内置或已选自建词对；同阵营使用同一个词。可能交换词对两端。不会为每个人抽互不相关的词。
4. 每人使用自己的手机私密领词，全部确认后才开始发言计时。没有传手机或玩家切换模式。
5. **沿用原代码：非白板玩家只看到词语，开局不显示自己的平民/卧底阵营**，以免改变猜测体验。白板明确提示没有词。此处需要用户/团队评审，因为草案PRD的“身份查看”表述可以有不同解释。
6. 每轮随机确定起始座位，按座位顺序让每名存活者描述一次，每人40秒。说完可以提前结束自己的回合；超时自动轮到下一位。主持人的经典界面没有跳过别人发言按钮。
7. 描述结束进入30秒投票。存活且有资格的玩家各自在手机上投票，不能自投，可弃权，超时未交算弃权；提交后不能改票。
8. 唯一最高票出局。普通轮平票则平票者加赛描述一次，其他存活玩家投票；加赛再平票无人出局。全弃权不淘汰。
9. 出局者的角色在结果中公开，但词语直到全局结束才公开。出局者不再发言和投票。
10. 找出所有卧底和白板，平民胜；卧底人数不少于平民，或存活人数不超过3且卧底阵营仍在，卧底胜。人数比较不把白板计入卧底人数。最多10轮，到达上限仍无平民胜利则卧底胜。
11. 普通轮结果展示8秒后自动进入下一轮/加赛。若当前票已满足胜利条件，直接进入终局并说明最后出局者。
12. 7人及以上可选择1名白板，白板属于卧底阵营；默认关闭。主持人提前结束会公开词语，不产生胜利奖励。现有引擎的得分事件仅保留为接口，本轮不实现统一排行榜。

需确认的决定：人数与卧底比例、是否显示自身阵营、白板机制、超时时长、自投/弃权、平票策略、胜负阈值、最大轮数、出局后身份/票明细可见性。

## 状态与命令

`设置 → word（私密领词）→ describe（描述）→ vote（投票）→ reveal（轮次结果）→ describe / ended（终局）`

- `acknowledgeWord`：只在领词阶段首次生效。重复确认返回同一状态，不重新发词、不重启计时。最后一位确认后开始描述。
- `turnDone`：只允许当前发言者在描述阶段提交。
- `vote`：只允许本轮有资格且尚未投票的玩家提交合法候选人或弃权。
- `tick`：到期后推进描述、投票和轮次结果；领词时无效。
- `endGame`：本机主持人可以结束；已结束的游戏拒绝再次结束。

公开视图包含确认进度、当前发言者和截止时间，不含未结束的词语或存活者角色；私密视图只返回绑定玩家的词。真实身份认证由后续平台适配承担；本地联调票据与传手机工具均不构成微信登录认证。

## 操作与验收

1. 从开发入口进入“谁是卧底”，默认选“每人一台手机”，默认6人。填写昵称（可留空），创建联调游戏，分发每位玩家的不同链接。
2. 每个人在自己的界面点击“查看我的词语”，确认后等待其他玩家；不能代别人确认。最后一位确认后才开始40秒发言计时。
3. 所有界面显示同一发言者，只有当前发言者能点“我说完了”；其他玩家看到等待状态。
4. 玩家各自在自己的界面选人或弃权，二次确认，提交后等待其他人的票。自己的界面始终保持原来的身份。
5. 淘汰后查看身份和票数，8秒后下一轮。用已看到的词语差异推断卧底，完成平民胜和卧底胜两种流程。
6. 终局查看所有角色和词，选择原班再开或回设置。切后台/离开页面会清空显示中的秘密词；重新进入须重新私密查看。

自动测试覆盖领词门槛、重复确认、公开信息保密、六人完整流程、两种胜利、非法操作，以及原有引擎规则回归。微信构建成功不能替代真机验收。

## 本轮范围

已实现C1-P0和C1-P1，并增加默认的固定玩家界面与多设备联调。英文词库/语言设置属于C3，融合画布属于C2。本地联调支持断线重新拉取快照；真实平台的房间、认证与统一计分仍未接入。




- 领词时最后一名未确认玩家退出，其余仍在场玩家全部确认后开始发言。
- 普通平票只加赛一次，加赛再平票无人出局；平票候选人离开至不足两人会取消加赛。
- 本机应用切回前台或刷新时按已过去的截止时间追赶进度。错过投票会算弃权，可能已经进入后续轮次或终局。
- 词卡在切后台或收到新版本局面时遮住。投票弹窗打开期间如局面改变，旧选择不提交。
- 正在提交时显示进度；无法确认结果时用原请求编号重试，不重复推进/计票。局面过期则刷新并重新选择。
- 从游戏返回设置后可以继续本局；在旧局未结束时重新开始，须先确认结束旧局。整次关闭应用后的游戏恢复不属于本机内存演示能力。
- 原班再开会让原有全部座位重新参加，包括上一局退出的人；确认进度、角色、发言、票数和局次重新开始。
