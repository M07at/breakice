# 微信词库管理烟测

在仓库根目录先构建小程序，再用 PowerShell 7.4+ 执行：

```powershell
npm --prefix app run build:mp-weixin
pwsh -File scripts/test-bank-smoke.ps1
```

需要已登录并开启服务端口的微信开发者工具。默认 CLI 路径可通过 `-WeChatCli` 覆盖。
脚本复制编译产物到忽略的 `app/reports/bank-smoke-project`，加入只存在于该副本的验收页。
预览或上传必须使用原始 `app/dist/build/mp-weixin`，不要使用验收副本。

烟测直接运行生产构建的题库模块和微信文件系统，覆盖：

- 谁是卧底、你画我猜、真心话、大冒险四类系统库可读且不可删除。
- 私有库创建、改名，题目增删改、重复校验、非法批次不部分写入、所有者限制。
- CSV/JSON 导入、导出、重复导入报告，以及内容、标签、难度和可画标记。
- 真正重启小程序后恢复 12 个测试库及其内容，随后只删除记录的测试库。
- UTF-8 中文文件读取和写出、取消文件选择。选择器和分享接口使用临时替身，文件系统真实运行；不会实际发送消息。

结果保存到 `app/reports/bank-smoke-native.json`。初次开发时另在实际管理页面用按钮新建库、
输入「苹果 / 香蕉」、保存，再修改为「苹果 / 西瓜」、删除库，均成功。

当前小程序自建词库存储在本设备；这些测试不代表它们已同步到 Supabase。
线上卧底开局仍使用服务端内置词对。云端共享自建库、将管理库接入线上开局是另外的集成工作，
不能凭这些本地管理烟测宣称已完成。原有 H5 共享开发仓库也不是 Supabase 生产词库。
