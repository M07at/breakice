# 破冰局开发顺序（谁先做什么）

核心原则：**先各自把不依赖别人的部分做完（用假数据 / 单机模式），再按依赖顺序接起来。**
整个项目的关键路径是 A：登录、房间、实时频道不通，所有多人功能都没法真机联调。所以 A 的平台核心要最先出，其他人在等待期间做自己的独立部分。

```
第 1 周  地基          C 仓库+CI ──┐   A Supabase+登录+房间表 ──┐
                                   ▼                            ▼
第 2–3 周 各做各的      B 画布(单机)   C 引擎+题库+页面(单机)   D 大厅页面(假数据)   A RLS+房间RPC+频道+AI
                                   │                            │
第 4–5 周 接平台        D 大厅 ↔ A 房间 → C 卧底 ↔ A/D → C 题库 ↔ A → B 笔画同步 ↔ A → B 计分 ↔ C/D
第 6–7 周 融合玩法      C 你画我猜谁是卧底 ↔ B 画布 + A AI；D 真心话 ↔ C 题库；分享卡片
第 8 周   打磨验收      断线重连、房主转移、包体积、20 台手机实测
```

## 第 0 步：开工前全组一起定（半天会议）

| 要定的事 | 谁出方案 | 为什么必须先定 |
|---|---|---|
| 分支规则、PR 规则、Gitee 保护分支 | C 出方案，仓库管理员设置 | 所有人都要往里提交（C 已出初版，见 `README.md` 和集成指南第 2 节） |
| 数据库命名规范和公共字段 | A | 每张表都要遵守，晚改代价大 |
| RPC 命名、错误返回格式、频道名 | A | B、C、D 的接口都按它写 |
| 设计系统用 Vant Weapp 还是 TDesign | D | 所有页面的组件库 |
| 小程序 AppID、谁是管理员 | 持有账号的人 | 真机预览和上传体验版都要 |
| 演示方式（体验版还是正式发布） | 全组 | 正式版需要 ICP 备案域名，要提前几周办 |

## 第 1 周：地基（这些不做完，别人没法开始联调）

- **C**：uni-app 工程、`npm run verify` 检查脚本、环境变量模板（已完成）；开通 Gitee Go 需要仓库管理员。
- **A**：建 Supabase 开发项目和微信云开发环境；用户表、房间表、房间成员表；登录云函数（`wx.login` → openid → 签发 Supabase JWT）。
- **B / D**：确认各自要的数据结构，把需求告诉 A。

## 第 2–3 周：各做各的（用单机 / 假数据，不互相等）

| 成员 | 独立可做 | 用什么代替别人的部分 |
|---|---|---|
| A | RLS、房间 RPC（建房、加入、准备、开始、离开、转移房主）、私有频道鉴权、广播工具、AI 评分服务（用测试图片调通） | 直接用 SQL 和脚本测试 |
| B | 画布组件（画、撤销、清空、颜色）、笔画数据格式、本地回放、计分逻辑、排行榜页面 | 本地笔画数组、假分数 |
| C | 谁是卧底引擎、题库模块（已完成）；卧底和题库页面 | `LocalUcBackend`、`MemoryBankRepository` |
| D | 设计系统、自我介绍卡组件、大厅和房间页面、真心话转盘 | 假房间数据、本地题目 |

## 第 4–5 周：接平台（按这个顺序，前一步通了再做下一步）

1. **D 大厅 ↔ A 房间**：建房、分享、扫码加入、准备。所有游戏都从房间开始，所以最先接。
2. **C 谁是卧底 ↔ A**：C 的表和服务端函数上线；**↔ D**：大厅选「谁是卧底」后进入 C 的页面。
3. **C 题库 ↔ A**：题库表和 RLS；B、D 改用 `qb_pick_items` 抽题。
4. **B 笔画同步 ↔ A 频道**：测端到端延迟 < 800ms。
5. **A AI 评分 ↔ B 评分展示**。
6. **B 统一计分 ↔ C、D 的计分事件**，排行榜实时更新。

## 第 6–7 周：融合玩法和收尾功能

- **C**：你画我猜谁是卧底，用 B 的画布和 A 的 AI。
- **D**：真心话接 C 的题库；微信分享卡片。
- **B**：Emoji 版、自定义版。

## 第 8 周：打磨和验收

断线重连 < 3s、房主转移、主包 < 2MB、冷启动 < 3s、20 台手机同房间实测、对照 16 条验收标准逐条过。

## 小组层面的风险（尽早处理）

- **合法域名**：体验版和正式版的小程序只能访问「服务器域名」里配置的 HTTPS/WSS 域名，而且域名要有 ICP 备案，`*.supabase.co` 加不进去。开发阶段可以关掉域名校验，但要给 20 个陌生人演示，就得有备案域名做反向代理（备案要几周）。如果只用体验版演示，每个人都要被加成体验成员，人数有限。请全组尽早决定。
- **用户内容审核**：自定义题库属于用户生成内容，正式发布审核时可能要求接入微信内容安全接口。
