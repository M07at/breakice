## 2. 房间是游戏单位

整个流程按房间组织，页面不直接碰后端：

1. 大厅 `pages/home` → 创建 / 加入房间（`pages/create`、`pages/join`）；
2. 房间 `pages/room`：成员列表、每人「我准备好了」、房主控制台；
3. **全员准备后**房主才能选玩法；`start_room_game` 与本机实现都会校验这一点；
4. 房间切到 `playing` 并记录 `game_type`，房主进入游戏；其他成员监听到 `lobby → playing` 后自动进入同一玩法；
5. 一局结束，房主「结束本局」→ 房间回到 `lobby`，准备状态重置（房主保持已准备）。

D 的真心话大冒险直接用房间玩家；C 的谁是卧底 / 融合玩法把房间名单作为座位昵称带进开设页；
B 的你画我猜用房间人数预填开局人数。

## 3. 后端接入（A）

`app/src/platform` 定义了一个 `RoomApi` 接口，两种实现：

| 实现 | 触发条件 | 能力 |
| --- | --- | --- |
| `LocalRoomApi` | 没配 Supabase | 建房、加入、准备、开局、结束、房主移交；状态在本机存储，只有一台设备能进房间 |
| `SupabaseRoomApi` | 配了 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` | 同上，但走后端：多设备进同一房间，2 秒轮询 + `heartbeat` 心跳 |

Supabase 侧用的接口（`docs/a/contracts.md`）：`wechat-auth` 登录、`create_room`、`join_room`、
`leave_room`、`set_ready`、`heartbeat`、`close_room`，以及本仓补充的 `start_room_game`、
`end_room_game`、`set_my_nickname`。客户端只用 `uni.request` 调 PostgREST / Edge Function，
没有引入 `@supabase/supabase-js`（小程序没有 `fetch` / `localStorage`，手写这层更可控，包也更小）。

## 4. 尚未完成（明确标注，不是完成状态）

1. **`uc-command` 还没实现**（A 的契约里标注为待办）。它负责在服务端跑 C 的规则引擎。
   因此「谁是卧底」在 Supabase 模式下只能进到开设页，没有服务端局次可以驱动；
   目前能完整跑通的仍是 C 的 H5 联调（`npm run dev:players`）。
2. **Realtime 授权策略未落地**：Supabase 实现用的是 2 秒轮询，不是私有频道广播。
3. **微信端登录未验证**：`wechat-auth` 函数已部署，但小程序 `mp-weixin.appid` 还是空的，
   用游客 AppID 时 `wx.login` 拿不到可用 code。现在可用的登录路径是 H5 的匿名登录
   （项目里已临时开启，正式发布前应关闭）。要验微信登录，需要把真实 AppID 填进
   `manifest.json` 并把小程序 AppID/Secret 配进 Supabase Secrets。
4. **B 的你画我猜仍是本机房间**（`LocalDrawRoomBackend`），同一台设备只有「我」实际作画；
   画布只在微信开发者工具里能画，H5 不能。
5. **C 的融合玩法画布仍是模拟适配器**。
6. **形象只在 D 的页面展示**：C / B / A 的玩家数据只有昵称。
7. **Gitee CI 未激活**。

### 这一轮在真实环境暴露并修掉的问题

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| `42703 column "id" ... does not exist` | 项目里已有早期原型的 `rooms` 表，`create table if not exists` 跳过它 | 建库脚本先把旧表改名 `rooms_legacy_backup` |
| `42883 operator does not exist: uuid = text` | `storage.objects.owner` 在不同 Storage 版本类型不同 | 两边显式 `::text` 比较（0005） |
| `42702 column reference "room_id" is ambiguous` | `join_room` 的输出参数与 `room_members.room_id` 同名 | `#variable_conflict use_column` + 列别名（0007） |
| `42501` 读表被拒 | 表没有给 `authenticated` 授 SELECT | `grant select on all tables`（0007） |
| 加入/创建后页面卡在表单 | `:loading` 按钮与页面跳转同帧 patch，uni-app H5 抛 `Cannot assign to read only property '_'` | 改用 `uni.showLoading` + `reLaunch` |
