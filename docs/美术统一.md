# 美术统一规则

目标：四个模块（D 大厅 / C 卧底 / B 你画我猜 / A 后端提示）的页面放在一起时，
**看起来是同一个应用**。下面是最小可执行的一套规则，新增页面照抄即可。

## 1. 只用设计 token，不写死颜色

`app/src/styles/tokens.scss` 定义在 `page` 上：

| token | 值 | 用途 |
| --- | --- | --- |
| `--brand` | `#4f46e5` | 主色：主按钮、当前态、强调数字 |
| `--brand-deep` | `#3730a3` | 主色上的深色文字 |
| `--brand-soft` | `#eef0ff` | 主色浅底：次级按钮、标签 |
| `--mint` / `--mint-soft` | 绿 | 成功、已准备、答对 |
| `--danger` | `#dc4c64` | 错误、退出 |
| `--warning` | `#d97706` | 倒计时紧张态 |
| `--ink` / `--muted` | 深/浅灰 | 正文 / 次要说明 |
| `--line` | `#e7eaf0` | 分割线 |
| `--surface` / `--canvas` | 白 / `#f6f8fb` | 卡片底 / 页面底 |
| `--radius-lg` / `--radius-md` | 28 / 20rpx | 大卡片 / 小控件 |
| `--shadow` | 12rpx 32rpx | 卡片阴影 |

**不要再出现 `#8a8f9c`、`#4f46e5` 这类字面量**，一律 `var(--muted)`、`var(--brand)`。

## 2. 页面骨架

```vue
<view class="page">            <!-- min-height: 100vh; padding: 24rpx; background: var(--canvas) -->
  <view class="head">…</view>  <!-- eyebrow(20rpx 灰) + title(34rpx 800) + muted(22rpx) -->
  <view class="surface">…</view> <!-- 白底 + var(--radius-lg) + var(--shadow)，每块间距 20rpx -->
</view>
```

## 3. 按钮

| 类型 | 样式 |
| --- | --- |
| 主操作 | 实心 `--brand`，白字，`--radius-md`，高 88rpx |
| 次要 | `--brand-soft` 底 + `--brand` 字 |
| 危险 | `--danger` 描边或实心，只用于「退出/关闭」 |
| 极小 | 高 56rpx，字号 22rpx，用于卡片内的「送花/差评」这类 |

同屏最多一个实心主按钮。

## 4. 名字与身份

同名玩家一律显示 **`昵称 #座位号`**，并按座位上色（6 色循环，见 `live.vue` 的 `.tone-*`）。
这条已经在你画我猜和融合玩法里生效，其他玩法接入时沿用。

## 5. 当前仍不一致的地方

| 位置 | 问题 |
| --- | --- |
| `pages-uc/*`（C 的页面） | 用的是 `uc-card` / `uc-button` 一套自己的样式，颜色接近但圆角、阴影与 token 不完全一致 |
| `pages-draw/setup|play`（B 的页面） | 原生的 `button` 默认样式，圆角 12rpx，与 token 的 20~28rpx 不一致 |
| `pages-bank/*` | 表格类页面，边框颜色用了 `#f0f1f5` |

统一这三处需要逐页替换样式，工作量约 0.5–1 天，**功能不受影响**，建议放在功能收尾之后做。

## 6. 已完成的部分

- 大厅、创建/加入、房间、二维码页：已经在用 token。
- 你画我猜联机页：本轮把硬编码颜色全部换成 token，页面底色、卡片圆角与阴影对齐大厅。
