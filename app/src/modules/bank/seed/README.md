# 系统题库（破冰局原创数据集）

这里的 JSON 是每个游戏默认的题库。玩家开局时默认用它们，也可以再加选自己建的题库。

| 文件 | 游戏 | 条数 | 谁看一下 |
|---|---|---|---|
| `undercover-pairs.json` | 谁是卧底 / 你画我猜谁是卧底 | 157 对（127 对可画） | C |
| `draw-words.json` | 你画我猜（含 Emoji 版） | 210 个词（164 个带 emoji） | B |
| `truth.json` | 真心话 | 69 题 | D |
| `dare.json` | 大冒险 | 52 题 | D |

## 怎么改

每条一行，直接增删改，然后在 `app/` 里跑 `npm test`：重复、超长、格式错误、敏感内容都会被单测拦下来。

```json
{"content":{"civilian":"苹果","undercover":"梨","drawable":true},"tags":["食物"],"difficulty":1}
{"content":{"word":"长颈鹿","hint":"动物","emoji":"🦒"},"tags":["动物"],"difficulty":1}
{"content":{"text":"你的 MBTI 是什么？你觉得准吗？"},"tags":["破冰"],"difficulty":1}
```

- `difficulty`：1 轻松、2 一般、3 难（真心话里 3 是比较走心的问题）
- `drawable`：谁是卧底的词对能不能画出来，融合玩法只抽 `true` 的
- `hint`：你画我猜的提示，一般写分类
- 词语最多 12 个字，题目 2–100 个字

## 内容原则

- 面向第一次见面的同学：轻松、友好，任何题都可以选择不回答 / 换一题
- 大冒险不涉及身体接触（击掌、合影都要对方同意）、不喝酒、不发朋友圈、不让人难堪
- 不放政治、色情、暴力、隐私类内容，避免小程序审核不通过

## 以后进数据库

接入 A 的数据库后，由 C 把这些 JSON 生成 SQL 种子数据，系统题库 ID 固定为 `sys_<游戏>`，题目 ID 为 `sys_<游戏>_<序号>`。
